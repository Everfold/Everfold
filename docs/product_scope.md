# 产品界面范围

## 首次启动

1. 窗口栏显示 Everfold, 正文只展示产品介绍, 语言默认跟随系统, 可在设置页修改; 可跳过或点击“开始使用”
2. 直接选择离线或集群; 离线方式进入工作区
3. 集群方式选择局域网, 自部署或测试云, 连接或登录等待 1 秒成功后点击下一步进入工作区
4. 明暗与配色采用默认偏好, 完整个性化配置保留在设置页
5. 之后启动直接打开工作区, 未完成时恢复上次引导阶段; 旧 preferences 阶段恢复到方式选择

跳过将连接方式设为离线并记录完成, 不重置已有外观偏好. 尚未开始连接时, 连接页可返回改选方式或跳过离线使用

连接页按后续后端接口交互设计, 当前连接与登录固定等待 1 秒后成功, 不访问真实服务. 连接中冻结配置, 返回与跳过操作. 成功不会自动跳转, 仅下一步按钮可用, 配置与其他按钮保持冻结; 下一步保存失败时仍可重试. 完成后直接进入工作区, 不再重复展示偏好设置

自部署提供 IP, 端口与验证方式: 无, 用户名/密码, 服务端证书, mTLS. mTLS 分别展示 CA, 公钥与私钥. 证书栏目提供本地文件与扫码两个来源, 当前只切换页面选择状态, 不读取文件或启动摄像头. 测试云显示用户名与密码

当前不验证地址, 端口, 账号或证书内容. 输入不写入偏好存储, 日志或账户状态, 不创建令牌. 初始化完成只记录引导阶段与连接模式, 不代表已经认证. 界面不显示开发阶段提示文字

使用方式只有离线与集群. 连接方式与工作节点选择独立, 集群中也可选择本机作为工作节点; 当前阶段只实现引导选择, 不实现节点调度或网络策略.

## 工作区

- 宽窗口侧栏上方显示新建会话和可折叠会话列表, 集群与设置固定在底部, 不随会话列表滚动; 窄窗口抽屉采用相同结构, 桌面主题窗口栏独立于导航
- 创建会话页的输入区与操作栏位于底部, 任务提示居中于上方剩余空间, 不重复展示软件名称, 不显示停止操作; 提交后上方切换为会话记录, 输入区保持底部位置
- 新建会话与会话列表之间使用分隔线; 会话列表默认展开, 可折叠, 导航切换保留当前展开状态, 不改变会话或草稿, 不写入持久化设置
- 支持独立会话草稿, 预设选择, 手动目录选择, 重命名与确认删除
- 默认会话名取首次提示词首行的前 12 个可见字符, 超出时加省略号, 不截断 Emoji 或组合字符. 后续消息不覆盖名称, 手动重命名不受默认截取长度影响
- 输入区的预设与工作区靠左, 模型选择与发送靠右; 窄窗口使用单行紧凑工具栏, 预设与工作区显示图标, 模型保留文字, 发送固定在右侧. 图标提供长按提示与无障碍语义, 模型默认始终未选择, 设置中也保留接入模型入口
- 集群与设置入口在工作台侧栏底部并列; 进入后切换到各自独立的导航界面, 不显示会话列表
- 设置侧栏当前提供“常规”, 集群侧栏当前提供“连接管理”, 现有内容分别由这两个入口承载, 后续可扩展子页面
- 两个界面都提供返回工作台入口; 宽窗口显示各自侧栏, 窄窗口使用各自抽屉. 返回恢复进入前的会话和草稿; 直接打开界面时返回工作台首页

桌面使用跟随现有主题的 Material AppBar 替代系统标题栏, 页面标题移入窗口栏, 正文不重复显示标题. 窗口栏位于路由与弹窗之外, 引导, 加载和错误状态也保留最小化, 最大化或还原, 关闭, 标题区拖动和双击操作; 普通窗口可从边缘缩放, 最大化或全屏后不显示缩放命中区. 引导的返回操作放在桌面底部操作区, 连接锁定规则不变. 原生能力不可用或恢复系统标题栏后, 宽窗口回退为原有正文标题, 窄窗口回退为原有菜单 AppBar. 手机布局保持不变. 正文使用父布局提供的可用空间, 不再统一指定 920dp 上限. 会话标题显示当前名称并随重命名更新, 空会话的任务提示与底部输入区各自管理滚动, 短窗口, 大字号和键盘占用空间时仍可访问操作栏. 设置只保留侧栏或 NavigationDrawer 入口, 不在右上角重复放置按钮

模型接入按钮和菜单项没有后续动作, 不打开表单, 弹窗或新页面, 不读取密钥, 不发请求

当前提交只把 Prompt 放入内存会话并显示未发送状态. 不创建模型回复, 不触发工具调用. 停止按钮仅在已有会话中保留禁用状态, 创建页不显示. 会话与草稿在进程结束后丢失, 设置与初始化状态会持久化

工作区选择仅保存用户明确选择的路径, 不扫描文件, 不自动关联整个设备目录, 不上传文件内容. 宽屏输入区显示目录名称, 紧凑布局用文件夹图标显示关联状态; 点击后可查看和复制完整路径, 更换或移除关联. 关联只属于当前会话, 不影响其他会话, 移除不会删除本地文件. 选择取消或失败时保留原路径

回复展示组件支持实际传入的助手 Markdown, 代码块复制, 可折叠的长消息, 公开思考摘要和独立工具输出. 用户提示词与工具输出保持原文. Markdown 使用标准 Material 文本, 列表和表格布局; 代码块与宽表格可横向滚动. 不加载远程图片, 不执行 HTML, 不自动打开链接. 数据样例仅用于独立组件预览和测试, 不自动注入正式会话

## 多集群管理

集群页复用 ConnectionForm 添加局域网, 自部署和测试云连接. 每个集群可独立断开, 重命名和确认移除, 不影响其他集群与会话. 断开后可修改配置并重新连接. 较宽窗口的弹窗底部将取消与连接或登录按钮放在同一操作区, 连接中冻结配置与取消操作, 成功后自动关闭并更新列表, 不要求点击下一步. 初始化向导仍保留下一步确认完成, 保存成功后进入工作区

连接表单在可用宽度小于 600dp, 或扣除键盘后的可用高度小于 480dp 时使用全屏对话框, 顶部提供关闭和连接或登录操作, 字段独立滚动并避让键盘. 其余窗口使用最大 560dp 的居中弹窗. 调整窗口大小保留已输入的配置与字段焦点, 连接期间两种布局均锁定取消, Esc 与系统返回. 自定义桌面窗口栏始终位于表单上方.

初始化连接成功后点击下一步, 会把该集群加入本次运行的集群列表. 集群列表与非敏感地址配置仅保存在内存中, 不跨重启恢复, 不把历史初始化完成状态解释成当前已连接

列表只记录名称, 服务类型, 地址, 端口和验证方式. 不保存用户名, 密码, 证书内容或私钥; 重连时这些输入需要重新提供. 当前仍采用 1 秒连接流程, 不访问后端

## UI 与实现边界

界面复用 material_ui 的 Scaffold, NavigationDrawer, ListTile, 标准按钮, 菜单, 对话框和输入控件, 不新增自定义主题或手绘控件. 语言与完整个性化设置由设置页的 SettingsContent 展示, 连接表单独立为 ConnectionForm

导航宽度, 列表项选中状态和组件样式交给库的默认实现, 不手工设置侧栏宽度. 菜单统一使用 MenuAnchor 和标准菜单按钮, 预设使用 RadioMenuButton

普通对话框按 M3 建议将整个弹窗限制为最大 560dp, 不把正文宽度误当成弹窗宽度. 页面不添加无规范依据的固定宽度上限, 保留必要的内边距, 滚动和键盘避让

工作区详情, 会话与集群重命名和颜色编辑在矮窗口, 大字号或键盘压缩空间时使用全屏对话框, 关闭与保存保留在顶部, 正文及详情操作可滚动. 切换布局保留编辑状态, 工作区路径不会因按钮堆叠而失去可视空间.

本阶段不实现 Everfold 后端, OAuth 或其他真实登录, 模型接入流程, Agent 执行引擎, 会话数据库或目录索引

现有 Rust 桥接与基础网络设施保留, 产品界面不自动初始化原生业务或后台网络连接

## 验证入口

```bash
flutter gen-l10n
dart analyze --fatal-infos lib test
flutter test --no-pub
flutter run -d linux
```

Nix 开发环境在 shellHook 中将 GTK 与桌面 GSettings schemas 加入 XDG_DATA_DIRS, 保留系统原有路径, 避免原生目录选择器因缺少 schemas 退出. 修改后重新进入 nix develop 或重载 direnv

lib/previews.dart 提供独立内存偏好的首次启动, 连接页, 集群页, 会话记录, 工作区详情和已初始化工作区预览, 每种分别包含移动端与桌面尺寸

自动测试涵盖初始化恢复与跳过, 连接等待时长与条件表单, 写入失败, 会话草稿隔离, 未发送状态, 导航, 摘要与工具记录展示, 以及窄屏和双倍字号布局. Linux 已完成构建, 实际启动, 热重载与桌面截图检查, 未发现 Flutter 运行时错误. 其他平台原生插件与真实渲染仍需在目标设备验证
