# 产品界面范围

## 首次启动

1. 展示 Everfold 介绍, 可跳过或开始初始化
2. 选择本地或云模式
3. 本地模式直接进入偏好设置; 集群模式选择局域网, 自部署或测试云
4. 连接或登录等待 1 秒成功后点击下一步, 设置语言, 明暗和颜色后完成初始化
5. 之后启动直接打开工作区, 未完成时恢复上次初始化阶段

跳过将连接模式设为本地并记录完成, 不重置已有外观偏好. 尚未开始连接时, 连接页可返回改选模式或跳过使用本地模式

连接页按后续后端接口交互设计, 当前连接与登录固定等待 1 秒后成功, 不访问真实服务. 连接中冻结配置, 返回与跳过操作. 成功不会自动跳转, 仅下一步按钮可用, 配置与其他按钮保持冻结; 下一步保存失败时仍可重试. 进入偏好设置后恢复正常导航

自部署提供 IP, 端口与验证方式: 无, 用户名/密码, 服务端证书, mTLS. mTLS 分别展示 CA, 公钥与私钥. 证书栏目提供本地文件与扫码两个来源, 当前只切换页面选择状态, 不读取文件或启动摄像头. 测试云显示用户名与密码

当前不验证地址, 端口, 账号或证书内容. 输入不写入偏好存储, 日志或账户状态, 不创建令牌. 初始化完成只记录引导阶段与连接模式, 不代表已经认证. 界面不显示开发阶段提示文字

本地模式指不连接 Everfold 云服务, 不等于强制离线. 未来仍可使用第三方模型 API

## 工作区

- 宽窗口左侧显示新会话, 会话列表, 集群和设置, 不保留全局顶栏; 窄窗口使用 Drawer 与标准菜单顶栏
- 空会话中央显示输入区, 提交后出现会话记录并将输入区固定在底部
- 支持独立会话草稿, 预设选择, 手动目录选择, 重命名与确认删除
- 输入区提供模型选择入口, 默认始终为未选择模型; 设置中也有接入模型入口
- 集群与设置并列, 在独立集群页管理多个连接, 不在设置中增加集群入口

桌面页面标题位于正文顶部并与内容左边缘对齐, 集群, 设置和会话使用统一的内容宽度上限. 手机标题只在顶栏显示一次. 会话标题显示当前名称并随重命名更新, 空会话保留居中欢迎区. 设置只保留侧栏或 Drawer 入口, 不在右上角重复放置按钮

模型接入按钮和菜单项没有后续动作, 不打开表单, 弹窗或新页面, 不读取密钥, 不发请求

当前提交只把 Prompt 放入内存会话并显示未发送状态. 不创建模型回复, 不触发工具调用, 停止按钮禁用. 会话与草稿在进程结束后丢失, 设置与初始化状态会持久化

工作区选择仅保存用户明确选择的路径, 不扫描文件, 不自动关联整个设备目录, 不上传文件内容. 输入区显示目录名称, 点击后可查看和复制完整路径, 更换或移除关联. 关联只属于当前会话, 不影响其他会话, 移除不会删除本地文件. 选择取消或失败时保留原路径

回复展示组件支持实际传入的助手 Markdown, 代码块复制, 可折叠的长消息, 公开思考摘要和独立工具输出. 用户提示词与工具输出保持原文. Markdown 使用标准 Material 文本, 列表和表格布局; 代码块与宽表格可横向滚动. 不加载远程图片, 不执行 HTML, 不自动打开链接. 数据样例仅用于独立组件预览和测试, 不自动注入正式会话

## 多集群管理

集群页复用 ConnectionForm 添加局域网, 自部署和测试云连接. 每个集群可独立断开, 重命名和确认移除, 不影响其他集群与会话. 断开后可修改配置并重新连接. 弹窗底部将取消与连接或登录按钮放在同一操作区, 连接中冻结配置与取消操作, 成功后自动关闭并更新列表, 不要求点击下一步. 初始化向导仍保留下一步进入偏好设置

初始化连接成功后点击下一步, 会把该集群加入本次运行的集群列表. 集群列表与非敏感地址配置仅保存在内存中, 不跨重启恢复, 不把历史初始化完成状态解释成当前已连接

列表只记录名称, 服务类型, 地址, 端口和验证方式. 不保存用户名, 密码, 证书内容或私钥; 重连时这些输入需要重新提供. 当前仍采用 1 秒连接流程, 不访问后端

## UI 与实现边界

界面复用 material_ui 的 Scaffold, Drawer, ListTile, 标准按钮, 菜单, 对话框和输入控件, 不新增自定义主题或手绘控件. 初始化和设置共用 SettingsContent, 连接表单独立为 ConnectionForm

本阶段不实现 Everfold 后端, OAuth 或其他真实登录, 模型接入流程, Agent 执行引擎, 会话数据库或目录索引

现有 Rust 桥接与基础网络设施保留, 产品界面不自动初始化原生业务或后台网络连接

## 验证入口

```bash
flutter gen-l10n
dart analyze --fatal-infos lib test
flutter test --no-pub
flutter run -d linux
```

Nix 开发环境在 shellHook 中将 GTK 与桌面 GSettings schemas 加入 XDG_DATA_DIRS, 保留系统原有路径, 避免原生目录选择器因缺少 schemas 退出. 修改后重新进入 nix develop 或重载 direnv

lib/previews.dart 提供独立内存偏好的首次启动, 连接页, 集群页, 会话记录, 工作区详情和已初始化工作区预览, 每种分别包含移动端与桌面尺寸

自动测试涵盖初始化恢复与跳过, 连接等待时长与条件表单, 写入失败, 会话草稿隔离, 未发送状态, 导航, 摘要与工具记录展示, 以及窄屏和双倍字号布局. Linux 已完成构建, 实际启动, 热重载与桌面截图检查, 未发现 Flutter 运行时错误. 其他平台原生插件与真实渲染仍需在目标设备验证
