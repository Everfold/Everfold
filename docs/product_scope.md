# 产品界面范围

## 首次启动

1. 展示 Everfold 介绍, 可跳过或开始初始化
2. 选择本地或云模式
3. 本地模式直接进入偏好设置; 集群模式选择局域网, 自部署或测试云
4. 连接或登录等待 1 秒成功后点击下一步, 设置语言, 明暗和颜色后完成初始化
5. 之后启动直接打开工作区, 未完成时恢复上次初始化阶段

跳过将连接模式设为本地并记录完成, 不重置已有外观偏好. 连接页可返回改选模式或跳过使用本地模式

连接页按后续后端接口交互设计, 当前连接与登录固定等待 1 秒后成功, 不访问真实服务. 成功不会自动跳转, 按钮切换为下一步; 修改配置后需重新连接

自部署提供 IP, 端口与验证方式: 无, 用户名/密码, 服务端证书, mTLS. mTLS 分别展示 CA, 公钥与私钥. 证书栏目提供本地文件与扫码两个来源, 当前只切换页面选择状态, 不读取文件或启动摄像头. 测试云显示用户名与密码

当前不验证地址, 端口, 账号或证书内容. 输入不写入偏好存储, 日志或账户状态, 不创建令牌. 初始化完成只记录引导阶段与连接模式, 不代表已经认证. 界面不显示开发阶段提示文字

本地模式指不连接 Everfold 云服务, 不等于强制离线. 未来仍可使用第三方模型 API

## 工作区

- 宽窗口左侧显示新会话, 会话列表, 云服务和设置; 窄窗口使用 Drawer
- 空会话中央显示输入区, 提交后出现会话记录并将输入区固定在底部
- 支持独立会话草稿, 预设选择, 手动目录选择, 重命名与确认删除
- 输入区提供模型选择入口, 默认始终为未选择模型; 设置中也有接入模型入口
- 云服务页面内容留空, 导航可用

模型接入按钮和菜单项没有后续动作, 不打开表单, 弹窗或新页面, 不读取密钥, 不发请求

当前提交只把 Prompt 放入内存会话并显示未发送状态. 不创建模型回复, 不触发工具调用, 停止按钮禁用. 会话与草稿在进程结束后丢失, 设置与初始化状态会持久化

工作区选择仅保存用户明确选择的路径, 不扫描文件, 不自动关联整个设备目录, 不上传文件内容

回复展示组件支持实际传入的助手文本, 可折叠公开思考摘要和工具状态. 这些状态的测试数据只存在于测试中, 不自动注入正式界面

## UI 与实现边界

界面复用 material_ui 的 Scaffold, Drawer, ListTile, 标准按钮, 菜单, 对话框和输入控件, 不新增自定义主题或手绘控件. 初始化和设置共用 SettingsContent, 连接表单独立为 ConnectionForm

本阶段不实现 Everfold 后端, OAuth 或其他真实登录, 模型接入流程, Agent 执行引擎, 会话数据库或目录索引

现有 Rust 桥接与基础网络设施保留, 产品界面不自动初始化原生业务或后台网络连接

## 验证入口

```bash
flutter gen-l10n
dart analyze --fatal-infos lib test
flutter test --no-pub
flutter run -d linux
```

Nix 开发环境在 shellHook 中将 GTK 与桌面 GSettings schemas 加入 XDG_DATA_DIRS, 保留系统原有路径, 避免原生目录选择器因缺少 schemas 退出. 修改后重新进入 nix develop 或重载 direnv

lib/previews.dart 提供独立内存偏好的首次启动, 连接页和已初始化工作区预览, 每种分别包含移动端与桌面尺寸

自动测试涵盖初始化恢复与跳过, 连接等待时长与条件表单, 写入失败, 会话草稿隔离, 未发送状态, 导航, 摘要与工具记录展示, 以及窄屏和双倍字号布局. Linux 已完成构建, 实际启动, 热重载与桌面截图检查, 未发现 Flutter 运行时错误. 其他平台原生插件与真实渲染仍需在目标设备验证
